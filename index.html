🚀 Curso Práctico de Git y GitHub

📁 1. Comandos Básicos de Terminal (CMD / Linux)

  • cd nombre_carpeta → Entrar en una carpeta
  • cd .. → Subir un nivel
  • dir / ls → Listar archivos
  • mkdir nombre_carpeta → Crear carpeta
  • "" > archivo.txt / touch archivo.txt → Crear archivo
  • ren archivo nuevo / mv archivo nuevo → Renombrar
  • code . → Abrir proyecto en VS Code

📦 2. Iniciar o Clonar un Repositorio

🔹 Iniciar repositorio desde cero

Convierte tu carpeta actual en un repositorio Git:

git init

🔹 Clonar repositorio existente

Descargar un repositorio de GitHub a tu computadora:

git clone URL_DEL_REPOSITORIO

✍️ 3. Preparar y Confirmar Cambios (Commit)

Agregar archivos al área de preparación (staging)

  • git add archivo.html → Agrega un archivo específico
  • git add . → Agrega todos los cambios
  • git add *.css → Agrega archivos con extensión específica

Confirmar cambios

  • git commit -m "Mensaje del cambio"
  • git commit -am "Mensaje" → Solo para archivos ya rastreados

Tip: Para archivos nuevos siempre usa git add primero.

🔎 4. Ver Estado del Proyecto

  • git status → Muestra estado actual
  • git log → Historial de commits
  • git diff → Ver cambios no agregados
  • git diff --staged → Ver cambios listos para commit

☁️ 5. Subir y Traer Cambios (Trabajo con GitHub)

  • git push → Sube cambios al repositorio remoto
  • git pull → Trae cambios del repositorio remoto

Buenas prácticas:

  • Antes de trabajar → git pull
  • Antes de subir → git pull y luego git push

🌿 6. Trabajo con Ramas

  • git branch → Ver ramas existentes
  • git checkout -b nueva-rama → Crear y cambiar de rama
  • git checkout nombre-rama → Cambiar de rama
  • git merge nombre-rama → Unir ramas (desde la rama destino)

Subir una rama nueva

git push -u origin nombre-rama

⏪ 7. Deshacer Cambios

  • git reset --soft HEAD~1 → Deshace commit pero mantiene cambios listos
  • git reset HEAD~1 → Quita del staging pero mantiene cambios
  • git reset --hard HEAD~1 → Borra completamente cambios
